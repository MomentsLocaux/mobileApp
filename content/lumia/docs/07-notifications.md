# Notifications

## Boîte de réception

Cloche en haut de l’**accueil** → liste des notifications reçues.

## Paramètres

**Paramètres → Gérer les notifications** :

- Moments **à proximité** et rayon
- Rythme / budget (éviter le spam)
- **Proximité live** (si activé dans le build)
- Rappels d’événements
- Activité **sociale pairs** (likes, follows…)
- Thèmes / catégories d’intérêt

Les options exactes dépendent de la version du build.

## Push

Les notifications push nécessitent l’autorisation système. Si refusée : Paramètres → Autorisations → notifications.

## Hors MVP

Pas de notifications « récompenses / missions Lumo », « Discovery Engine », ou « créateur suivi » tant que les flags V2 correspondants sont off.

## Lumia

Lumia n’envoie pas de push et ne modifie pas les préférences à ta place : elle explique où les régler.
