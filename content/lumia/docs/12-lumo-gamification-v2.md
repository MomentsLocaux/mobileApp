# Lumo, check-in, boutique (hors MVP par défaut)

Ces surfaces sont **désactivées** dans le build MVP store-ready sauf flags explicites.

## Check-in (`FEATURE_CHECKIN`)

QR ou géolocalisation **sur place** pour marquer sa présence à un moment. Peut déclencher des récompenses Lumo si gamification activée.

Si le flag est off : l’option n’apparaît pas — ne pas la décrire comme disponible.

## Gamification (`FEATURE_GAMIFICATION`)

- **Lumo** — monnaie virtuelle gagnée via check-in, missions, etc.
- **Boutique** — boosts, cosmétiques, effets (pas achat de places événement)
- **Missions** — défis in-app
- **Pass partenaires** — avantages partenaires selon catalogue

CGU peuvent inclure une section Lumo si gamification ON.

## Discovery Engine (`FEATURE_DISCOVERY`)

Fonctionnalités type Éclaireur : idées maintenant, carte de zone, recommandations, insights. Paramètres Discovery visibles si entitlement Éclaireur + flag ON.

## Concours (`FEATURE_CONTESTS`)

Module concours V2 — hors MVP.

## Lumia

Expliquer ces modules **uniquement** si l’utilisateur les voit ou si la question est générale sur « à quoi sert Habitué » sans promettre qu’ils sont actifs dans le build actuel.
