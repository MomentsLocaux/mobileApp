# Acteurs locaux

**Source produit validée :** page site `/acteurs-locaux` (août 2026).

## Message central

> Vous faites déjà vivre le territoire. Faisons-le savoir.

Moments Locaux donne à vos événements une **nouvelle surface de découverte** auprès des habitants, visiteurs et personnes déjà présentes à proximité.

## Un rôle, pas une étiquette

> Vous êtes Diffuseur dès que vous faites circuler des événements.

Le rôle dépend de **ce que vous faites**, pas de votre statut juridique.

## Les deux portes

| Rôle | Quand | Action |
|---|---|---|
| **Moments Diffuseur** | Vous publiez / relayez des **dates** | Rendre la programmation visible, réutiliser vos sources existantes |
| **Moments Partenaire** | Vous **accueillez** | Proposer une attention aux personnes déjà de sortie autour de vous |

Un même lieu peut **cumuler** les deux (ex. café : concert propre + attention avant le spectacle voisin).

## Timing

Les **espaces professionnels** ouvriront **après le lancement de l'app**. Vous pouvez **déjà** présenter votre activité à l'équipe.
