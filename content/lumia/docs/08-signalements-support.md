# Signalements et support

## Signaler un contenu ou un profil

Depuis l’écran concerné (menu ⋯ ou équivalent) :

- **Événement** — signalement utilisateur
- **Commentaire** — signalement
- **Profil membre** — signalement

Le signalement est enregistré pour traitement par l’équipe via l’**outil web admin** (modération). L’app mobile MVP **ne montre pas** de file de modération ni de boutons approuver / refuser.

## Reporter un bug ou une suggestion

Menu profil → **Reporter un bug** (route `/bug-report`).

Catégories : bug, UX, suggestion. Décrire les étapes, le comportement attendu, éventuellement une capture.

## Contact email

Support et privacy : **hello@moments-locaux.com**

Pour un problème de compte, données personnelles ou litige : privilégier email ou parcours Paramètres → Confidentialité.

## Lumia

Lumia peut expliquer **comment** signaler ou contacter le support. Elle ne traite pas les signalements et ne modère pas.
